# Legacy release documentation

This directory preserves pre-RC643 public manuals and source indexes as
migration and audit history. They are not active release assets, are not part
of the current validation matrix, and must never be selected by the
authenticated `/manual` routes.

The current public documentation is the RC643/R75 set at `docs/`; the only
packaged manual assets are the matching RC643 files under
`magi_v3/manual_assets/`.
